# Evaluacion-web01-practica

Nombre del proyecto: Destino Cordillera
Integrantes: Benjamín Lagos, Adrián Mancilla, Vianca Viveros.

Esta página web busca dar a conocer el recinto turístico "Destino cordillera" el cual cuenta con diversos servicios a prestar para los usuarios, entre ellos su zona de alojamiento (Un hotel y una zona de camping), zona gastronómica (Restaurante y minimarket), además de una amplia oferta de servicios de entretenimiento y relajación. Para esto la web contiene su inicio ofreciendo al usuario ir a los servicios con más detalle, para luego en sus respectivas páginas propias dar más detalle y hacer el enganche con un botón que los lleve a reservar con la empresa.

Para visualizar este sitio web e interactuar con el se deben seguir los siguientes pasos:
  - Clonar el repositorio: - Abre tu terminal o cmd.
                           - Clona el repositorio con: git clone https://github.com/benjitaminmon/Evaluacion-web01-practica.git
  - Ingresar a la carpeta del proyecto : cd Evaluacion-web01-practica
  - Abre el archivo index.html directamente en el navegador web de preferencia haciendo doble clic sobre él: start index.html

Las tecnologías usadas para este desarrollo fueron: HTML5; CSS3; Bootstrap.
